## Επόμενα features (σειρά προτεραιότητας)

1. Κατέβασμα PDF από τον κώδικα iOS (χωρίς τον περιορισμό CORS του web).
2. Προβολή PDF μέσα στην εφαρμογή, με αναζήτηση στο κείμενο.
3. Σαρωτής εγγράφων του iOS (VisionKit): ίσιωμα σελίδας, πολυσέλιδο PDF για εγχειρίδια χωρίς ψηφιακή έκδοση.
4. Ενεργοποίηση και δοκιμή iCloud σε iPhone και iPad (capability, container — μόνιμο όνομα με το προσωρινό `appId`).
5. Αυτόματη εύρεση εγχειριδίου με AI (θέλει server, κλειδί API, κόστος — απόφαση).
6. Προετοιμασία App Store: όνομα, εικονίδιο, πολιτική απορρήτου, στιγμιότυπα.
7. Προειδοποίηση npm για τα install scripts (allowScripts).

## Να ελεγχθεί στη συσκευή

- Υπενθυμίσεις λήξης εγγύησης (δεν έχουν ελεγχθεί στο iPhone).
- Σάρωση πραγματικού εντύπου: ακρίβεια μάρκας/μοντέλου/QR, χρόνος.
- Πόσο συχνά αποτυγχάνει το κατέβασμα PDF (CORS).
- Εισαγωγή αρχείου `.mbackup` από τα Αρχεία του iOS (αν ο επιλογέας το αφήνει να επιλεγεί).
- Ρυθμίσεις → Ασφάλεια: «Keychain της συσκευής» και «Face ID διαθέσιμο».
