# Εγχειρίδια (όνομα εργασίας)

Εφαρμογή για iPhone και iPad: φωτογραφίζεις το έντυπο εγχειρίδιο ενός προϊόντος, βρίσκεις και κρατάς το ψηφιακό του, και
το χαρτί πάει ανακύκλωση. Μαζί με το προϊόν φυλάς εγγύηση, παραστατικό αγοράς, σημειώσεις και τους συνδέσμους των QR.

Ίδιο stack με το GF Smart Choice: Vite + React 19 + TypeScript + Tailwind 4, πακεταρισμένο με Capacitor 8 για iOS.
Το όνομα «Εγχειρίδια» και το `appId` `gr.yiami.manuals` (`capacitor.config.ts`) είναι προσωρινά.

## Τι κάνει σήμερα

- **Σάρωση εξωφύλλου** (κάμερα ή φωτογραφία): ανάγνωση QR / barcode και κειμένου στη συσκευή, πρόταση μάρκας, μοντέλου,
  κατηγορίας. Ο χρήστης ελέγχει πριν αποθηκευτεί οτιδήποτε.
- **Αρχειοθέτηση QR**: σύνδεσμοι βίντεο, PDF, εφαρμογών, σελίδων. Δεν ανοίγουν ποτέ αυτόματα· μόνο http/https.
- **Εύρεση ψηφιακού**: σύνδεσμος από το QR, έτοιμες αναζητήσεις (DuckDuckGo ή Google), κατέβασμα PDF από διεύθυνση,
  εισαγωγή αρχείου, ή φωτογράφιση σελίδων όταν δεν υπάρχει ψηφιακό.
- **Εγγύηση**: ημερομηνία αγοράς + διάρκεια ή ρητή λήξη, κατάσταση (ενεργή / λήγει σύντομα / έληξε).
- **Παραστατικό**: σάρωση ή εισαγωγή (PDF, εικόνα), με πρόταση ημερομηνίας αγοράς από το κείμενο της απόδειξης.
- **Αναζήτηση και φίλτρα**: χωρίς τόνους, με λατινικούς χαρακτήρες, με ανοχή σε ένα λάθος, κωδικοί χωρίς παύλες· φίλτρα με πλήθη.
- **Αντίγραφο ασφαλείας** σε ένα `.zip` (εξαγωγή / εισαγωγή με συγχώνευση).
- **Συγχρονισμός iCloud** (μόνο στην εφαρμογή iOS, κλειστός μέχρι να τον ανοίξει ο χρήστης) — βλ. `docs/icloud-sync.md`.
- **Κρυπτογράφηση στη συσκευή** (AES-256-GCM, κλειδί στο Keychain) και **κλείδωμα με Face ID** — βλ. `docs/security.md`.
- Ελληνικά και αγγλικά, φωτεινή και σκοτεινή εμφάνιση, δύο στήλες σε iPad.

## Τι ΔΕΝ υπάρχει ακόμη

- **Δοκιμή του συγχρονισμού iCloud.** Η λογική (`src/data/syncEngine.ts`) καλύπτεται από τεστ, αλλά το plugin Swift δεν έχει
  μεταγλωττιστεί ούτε τρέξει, και χρειάζεται το capability iCloud στο Xcode. Βλ. `docs/icloud-sync.md`.
- **Αυτόματη εύρεση του εγχειριδίου με AI** (φωτογραφία → αναζήτηση → PDF). Θέλει server και API key.
- **Δοκιμή σε πραγματική συσκευή / Safari.** Όλες οι δοκιμές έγιναν σε Chromium. Οι κλάδοι «native» του
  `src/services/platform.ts`, τα plugins Swift (iCloud, Keychain, Face ID) και το iOS project δεν έχουν τρέξει ποτέ.
- Κρυπτογράφηση του αντιγράφου ασφαλείας `.zip`, ειδοποιήσεις λήξης εγγύησης.

## Ξεκίνημα

Χρειάζονται Git και Node 26 (η έκδοση είναι στο `.nvmrc`). Για την εφαρμογή iOS, Mac με Xcode.

Node σε Mac με Apple Silicon: `brew install node` από το Homebrew στο `/opt/homebrew` (όχι παλιό Homebrew για Intel στο
`/usr/local`, που δεν έχει πια έτοιμα πακέτα και προσπαθεί να χτίσει το Node από τον πηγαίο κώδικα). Έλεγχος με
`which node && node -v`· αν δείχνει παλιά έκδοση αμέσως μετά την εγκατάσταση, `hash -r`. Με `nvm`: `nvm install && nvm use`.

```bash
git clone https://github.com/imichelakos/manuals-app.git
cd manuals-app
git config core.hooksPath .githooks # σάρωση μυστικών πριν από κάθε commit
npm ci
npm run dev                         # http://localhost:3100
```

### Εντολές

```bash
npm run build      # αντιγράφει OCR/wasm στο public/, έλεγχος τύπων, build στο dist/
npm run tests      # τεστ λογικής
npm run test:i18n  # κάθε ελληνικό κείμενο έχει αγγλική μετάφραση
npm run lint
npx playwright install chromium   # μία φορά
npm run e2e        # σενάριο σε Chromium (διαστάσεις iPhone και iPad) πάνω στο dist/
```

### iPhone και iPad (Mac με Xcode)

Το Xcode project βρίσκει τα plugins μέσα στο `node_modules`, άρα πρώτα `npm ci` και build:

```bash
npm run build
npx cap sync ios
npx cap open ios
```

Στο Xcode, στόχος **App** → *Signing & Capabilities*: *Automatically manage signing* και η ομάδα ανάπτυξης.

- **Simulator:** διάλεξε έναν iPhone και έναν iPad simulator από τη λίστα συσκευών και ▶. Η εφαρμογή υποστηρίζει και τα
  δύο· έλεγξε και τις δύο διατάξεις (μία στήλη στο iPhone, δύο στο iPad οριζόντια). Στον simulator το Face ID
  ενεργοποιείται από το μενού *Features → Face ID → Enrolled* και δοκιμάζεται με *Matching Face* / *Non-matching Face*.
- **Συσκευή:** σύνδεσε το iPhone ή το iPad, ξεκλείδωσέ το, διάλεξέ το ως προορισμό και ▶. Την πρώτη φορά η συσκευή ζητά
  να εμπιστευτείς τον προγραμματιστή (*Ρυθμίσεις → Γενικά → VPN και διαχείριση συσκευών*) και να ενεργοποιήσεις τη
  *Λειτουργία προγραμματιστή*.
- **iCloud:** για τον συγχρονισμό χρειάζεται επιπλέον το capability iCloud → CloudKit — βλ. `docs/icloud-sync.md`.

Μετά από κάθε αλλαγή στον κώδικα web: `npm run build && npx cap sync ios` και ξανά ▶.

## Δομή

| Φάκελος | Περιεχόμενο |
|---|---|
| `src/domain` | Καθαρή λογική χωρίς οθόνη/δίσκο: μοντέλο (zod), εγγύηση, αναζήτηση, αναγνώριση μάρκας/μοντέλου, κωδικοί QR, συγχώνευση. Καλύπτεται από τα `tests/`. |
| `src/data` | Αποθήκευση: IndexedDB, βιβλιοθήκη, αρχεία (`BlobStore`), αντίγραφο ασφαλείας, ρυθμίσεις, συγχρονισμός (συμβόλαιο, μηχανή, εκκίνηση). |
| `src/services` | Συσκευή: εικόνα, OCR (Tesseract), ανάγνωση QR (ZXing wasm), κατέβασμα PDF, διαφορές iOS / browser, γέφυρα iCloud. |
| `src/components`, `src/pages` | Οθόνες. |
| `src/i18n` | Ελληνικά ως κλειδιά στον κώδικα, αγγλικά στο `en.ts`. |

## Απόρρητο και ασφάλεια

- OCR και ανάγνωση QR τρέχουν στη συσκευή· γραμματοσειρές, wasm και δεδομένα γλωσσών σερβίρονται τοπικά, χωρίς CDN.
- Η μόνη κλήση δικτύου της εφαρμογής είναι το κατέβασμα ενός PDF από διεύθυνση που δίνει ο χρήστης
  (`src/services/download.ts`: μόνο https, χωρίς cookies, έλεγχος ότι το περιεχόμενο είναι PDF). Γι' αυτό το CSP έχει
  `connect-src https:`.
- Ό,τι έρχεται από έξω (αντίγραφο ασφαλείας, QR, αρχεία) ελέγχεται πριν χρησιμοποιηθεί: σχήματα zod, έλεγχος περιεχομένου
  αρχείων, όρια μεγέθους.
- Τα δεδομένα στη συσκευή είναι κρυπτογραφημένα (`docs/security.md`). Το αντίγραφο `.zip` δεν είναι.

## Σημειώσεις OCR

Κάθε γλώσσα διαβάζεται σε δικό της πέρασμα (`src/services/ocr.ts`). Σε δοκιμές με συνθετικές εικόνες, το ελληνικό μοντέλο
παραμόρφωνε λατινικούς κωδικούς και ψηφία, και η προεπιλεγμένη διάταξη (ενιαίο μπλοκ) αγνοούσε το μεγάλο λογότυπο· γι' αυτό
τα εξώφυλλα διαβάζονται ως «σκόρπιο κείμενο» και μάρκα/μοντέλο/ημερομηνίες προέρχονται από το αγγλικό πέρασμα. Δεν έχει
δοκιμαστεί με φωτογραφίες πραγματικών εντύπων.
